# OpenSim-Aura

OpenSim-Aura is a fork of [OpenSimulator](https://github.com/opensim/opensim). It focuses on Hypergrid travel, asset transfer, baked textures (XBakes and Firestorm server-side bake), profiles, attachment scripts, friends, instant messages, display names, UUID DHT lookup, Hypergrid groups, and SQLite standalone backends.

OpenSim-Aura is **alpha**, the same as stock OpenSim. It is provided as is. It is experimental and may have bugs and security issues. Do not install it on a local machine or network that holds sensitive data. Use a container or a dedicated server.
